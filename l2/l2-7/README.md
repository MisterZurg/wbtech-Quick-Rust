# L2.7 Подсчет символов
Задача
    Создайте утилиту lf (letter frequency), которая возвращает информацию о том, как часто встречается та или иная буква в тексте из входного файла. Подсчитывать следует только символы латинского алфавита.

**Требования**
Вывод должен выглядеть как словарь, символ — частота встречаемости. Также следует вывести количество затраченного времени на подсчет символов.

Вывод оформить в json формате. Для упрощения, будем считать, что входной файл может быть целиком загружен в память.

Также, требуется добавить возможность использовать ключ -t позволяющий задать количество потоков, которое будет задействовано для подсчета частоты встречаемости символов. Без данного параметра, программа должна использовать только один поток для подсчета встречаемых символов.

**Например:**

Ввод: 
```sh
lf -t 4 report.txt
```

Вывод:
```json
{
  "elapsed": "2.174 s",
  "result": {
    "a": 5423,
    "b": 1342, 
    "c": 3572
    /* ... */
  }
}
```
